# Rust FPS Optimizer by undeq
Windows optimizer focused on improving Rust performance.
## Features
- MAX FPS profile
- Balanced profile
- Restore
- Game Mode
- Game DVR control
- High Performance power plan
- TEMP cleaner
- CPU / GPU / RAM detection
- Registry backup
- Registry restore
- Windows x64 self-contained EXE
## Build
The project uses .NET 8 and WPF.
GitHub Actions automatically builds:
RustFPSOptimizer_by_undeq.exe
## Safety
The optimizer does not disable:
- Windows Defender
- Easy Anti-Cheat
- Windows security components
Only settings changed by the optimizer are backed up for restore.
